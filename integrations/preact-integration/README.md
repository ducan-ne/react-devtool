# Preact Integration Test

This project demonstrates the integration of the react-devtool library with a Preact application.

## Features

- Uses Preact with TypeScript
- Integrates the react-devtool library
- Shows how to use the Devtool component in a Preact application

## Development

```bash
# Install dependencies
pnpm install

# Run development server
pnpm run dev

# Build for production
pnpm run build

# Preview production build
pnpm run preview
```

## Implementation

The main App component imports and uses the `Devtool` component from react-devtool, demonstrating that the library works with Preact as well as React.
